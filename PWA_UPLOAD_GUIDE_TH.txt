MCI 2D sim · PWA for GitHub Pages

เว็บไซต์ปลายทาง:
https://undpun.github.io/MCI-animation/

วิธีติดตั้งไฟล์:
1. สำรองไฟล์เดิมใน repository ก่อน
2. นำไฟล์และโฟลเดอร์ทั้งหมดภายในแพ็กเกจนี้ไปวางที่ root ของ repository MCI-animation
3. ต้องให้ index.html, manifest.webmanifest และ service-worker.js อยู่ระดับเดียวกัน
4. Commit การเปลี่ยนแปลงและรอ GitHub Pages deploy
5. เปิดเว็บไซต์ใหม่หนึ่งครั้งขณะต่ออินเทอร์เน็ต

ติดตั้งบน iPhone/iPad:
Safari > Share > Add to Home Screen

ติดตั้งบน Android/Desktop Chrome:
เปิดเมนู Browser > Install app หรือ Add to Home screen

หมายเหตุ:
- หน้าเกมและ assets ที่เคยเปิดจะถูก cache เพื่อให้เปิดเร็วขึ้น
- Firebase realtime และการเล่นหลายคนยังต้องใช้อินเทอร์เน็ต
- เมื่ออัปเดตเกมรุ่นถัดไป ให้เปลี่ยนค่า CACHE_VERSION ใน service-worker.js
  เพื่อบังคับให้เครื่องผู้เล่นรับไฟล์ cache ชุดใหม่
